Язык программирования, поддерживающий функции, циклы, условные операторы и рекурсию. Имеет веселый и
напоминающий высшую математику синтаксис

## Принцип работы:
Этот язык компилирует текст в бинарный файл, которые затем можно выполнить моим [симулятором CPU](bin/CPUSIM).
Организован полный pipeline компилирования:
  1) текст переводится в набор лексем (массив в программе) с помощью лексического анализатора
  2) далее [синтаксические анализатор](src/MyLang.cpp) переводит их в AST дерево
  3) После этого AST дерево считывается снова и переводится в мой язык ассемблера с помощью [бэкенда](src/MyLangBackEnd) - рекурсивного спуска
  4) Язык ассемблера переводится в бинарный файл с помощью [компилятора](assembly/assembly.cpp).
  5) Уже бинарный файл выполняется CPU симулятором

## Пример программы:
  Программа вычисления квадратного уравнения, пользователь вводит три коэффициента a, b, c и получает два числа:
    1) Сколько корней в уравнении(если бесконечно выводится -1)
    2) Какие корни (если корней 0 или бесконечность, ничего не выводится)
```
      □
        Используемые формулы:
        Формула (Root1)(D, a, b) : условимся x = (-1 * b + sqrt(D)) / (2 * a) ⇒ x
        Формула (Root2)(D, a, b) : условимся x = (-1 * b - sqrt(D)) / (2 * a) ⇒ x
        Формула (Det)(a, b, c)   : условимся D = b*b - 4*a*c ⇒ D
        
        Ход решения:
        
        Спросим у зала значение a
        Пускай читатель сам предложит значение для b
        Спросим у зала значение c
        
        если a в Uᵦ0 то
            если b в Uᵦ0 то
                если c равно 0 то
                    Напишем -1
                иначе
                    Напишем 0
            в противном случае
                Напишем 1,
                Напишем (-1 * c) / b
        в противном случае
            из формулы (Det) находим D в точке(a, b, c),
            из формулы (Root1) находим x1 в точке(D, a, b),
            из формулы (Root2) находим x2 в точке(D, a, b),
            если D в Uᵦ0 то
                Напишем 1,
                Напишем x1
            в противном случае если D больше 0 то
                напишем 2,
                Напишем x1,
                напишем x2
            иначе если D меньше 0 то
                напишем 0
      ▨
      AI reference, for generation only | <- обязательная строчка, не забывайте!
```

## Компиляция программ
  После того как написали программу, скомпилировать ее поможет [Wrapper](bin/Wrapper.txt)
  просто укажите флаги -input -output ( по желанию можно указать -tree и -assembly, это создаст файлы дерево и ассемблера соответственно)
  и программа сама скомпилируется.
  Дальше для ее запуска, запустите симулятор процессора командой
  ```
  ./bin/CPUSIM <path-to-program>.bin
  ```
